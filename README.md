# ТокКлип — стартовый проект

Самостоятельный сайт активности сообщества «Аватарский KlipTok».

## Состав
- `index.html` — главная страница.
- `styles.css` — неоновый адаптивный дизайн.
- `app.js` — клиентская логика (пока демонстрационный режим).
- `gas/Code.gs` — начальная серверная логика Google Apps Script.

## Публикация сайта на GitHub Pages
1. Создайте отдельный публичный GitHub-репозиторий, например `tokclip`.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/root`.
5. Сохраните настройки. GitHub покажет адрес опубликованного сайта.

## Подключение Google Apps Script
1. Создайте отдельную Google Таблицу для ТокКлип.
2. Скопируйте ID таблицы из адреса: часть между `/d/` и `/edit`.
3. Создайте проект Google Apps Script и вставьте содержимое `gas/Code.gs`.
4. Укажите ID в `CONFIG.SPREADSHEET_ID`.
5. Запустите `setupSheets()` из редактора и подтвердите доступ.
6. Заполните листы «Клипы» и «Задания». Для активного клипа укажите `status=active`.
7. Разверните проект как Web App. Для публичного пользовательского API доступ «Anyone» означает, что endpoint открыт всему интернету; перед запуском добавьте серверную защиту от злоупотреблений и настройте права таблицы.
8. Скопируйте URL Web App в `API_URL` в `app.js`.

## Важные замечания перед реальным запуском
Это стартовый каркас, а не готовая конкурсная система. Сейчас реализована только базовая серверная выдача задания и проверка уникальности пары VK ID + clip_id под блокировкой.
Нужно добавить до публичного запуска:
- подтверждение владения VK ID (самостоятельно введённый ID не подтверждает аккаунт);
- проверку/нормализацию ID клипа на сервере и запрет редактирования активного клипа;
- отправку ссылки на комментарий и валидацию ссылки;
- административную авторизацию и роли;
- модерацию заявок;
- розыгрыш с защитой от повторного запуска и сохранением результата;
- интеграцию с реальным реестром ТокКоинов и идемпотентное начисление;
- ограничения частоты запросов, журналирование и резервное копирование.

Не размещайте секреты, ключи или административные пароли в GitHub Pages.
